### 🎯 Objective

My objective is to build a strong foundation as a SOC Analyst, Threat Hunter, and Penetration Tester while continuously developing the investigative, offensive, and defensive skills required to understand modern cyber threats. My long-term goal is to grow into a senior cybersecurity professional specializing in Digital Forensics, Threat Hunting, and Penetration Testing, with the ability to investigate incidents, identify attacker behavior, and validate security controls through ethical offensive testing.

### 👋 Bio

I'm **Eugen Nyongesa**, a Software Engineering graduate transitioning into cybersecurity with a strong interest in understanding how attacks happen, how they can be detected, and how systems can be strengthened against them.

My current focus is on **SOC operations, threat hunting, and penetration testing** — developing practical skills in security monitoring, network analysis, incident investigation, vulnerability assessment, web application security, and adversary behavior. I approach cybersecurity from both sides: learning to **detect and investigate threats** while also understanding the techniques attackers use to compromise systems.

I use this GitHub as a practical security workspace where I document labs, experiments, tooling, investigations, detection techniques, and penetration-testing projects as I continue building my capabilities.

### 📚 What I'm Building

This profile documents my progression through practical cybersecurity work.

- 🟢 **Threat Hunting Labs** — ATT&CK-driven hunts, IOC analysis and adversary behavior

Cybersecurity is a continuous learning process.

I believe the best way to grow is to **build, investigate, document, share, and learn from others**. My repositories are intended to show not only the final result, but also the reasoning, methodology, challenges, and lessons learned along the way.
